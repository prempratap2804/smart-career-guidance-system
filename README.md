# 🎯 Smart Career Guidance System

An ML-based career guidance system that recommends suitable career paths based on a user's interests, skills, aptitude, abilities, and work preferences.

## 🚀 Features

* Machine Learning-based career recommendation
* Random Forest Classifier
* Flask-based backend
* Input validation
* Categorical data encoding using LabelEncoder
* Top 3 career recommendations
* Confidence scores for predicted careers
* Separate trained model and encoder files

## 🧠 Machine Learning

The system uses a **Random Forest Classifier** to predict a suitable career based on the user's profile.

### Input Features

The model considers the following factors:

* Interest Area
* Aptitude Level
* Communication Skills
* Programming Skill
* Mathematical Ability
* Problem-Solving Skill
* Creativity Level
* Work Preference

The target variable is **Recommended_Career**.

The data is split into **80% training data and 20% testing data** before training the model.

The Random Forest model is configured with **200 decision trees**.

## ⚙️ How It Works

```text
User Input
    ↓
Input Validation
    ↓
Label Encoding
    ↓
Trained Random Forest Model
    ↓
Career Prediction
    ↓
Top 3 Career Recommendations
    ↓
Confidence Scores
```

The Flask application loads the trained model and saved encoders when the application starts.

User inputs are validated and converted into the same encoded format used during model training.

The system then predicts the recommended career and returns the top 3 career options with their confidence scores.

## 🔌 API

### POST `/predict`

The application provides a `/predict` endpoint for career prediction.

Example input:

```json
{
  "interest_area": "AI/ML",
  "aptitude_level": "High",
  "communication_skills": "Good",
  "programming_skill": "Intermediate",
  "mathematical_ability": "High",
  "problem_solving_skill": "High",
  "creativity_level": "Medium",
  "work_preference": "Both"
}
```

Example response:

```json
{
  "career": "Machine Learning Engineer",
  "top3": [
    {
      "career": "Machine Learning Engineer",
      "confidence": 82.5
    },
    {
      "career": "Data Scientist",
      "confidence": 11.0
    },
    {
      "career": "Data Analyst",
      "confidence": 6.5
    }
  ]
}
```

*The actual prediction and confidence values depend on the trained model and user input.*

## 🏋️ Model Training

To train the model again using the dataset:

```bash
python train_model.py
```

The training script performs:

* Dataset loading
* Null and duplicate checking
* Categorical feature encoding
* Train-test splitting
* Random Forest training
* Model evaluation
* Saving the trained model
* Saving the encoders

The trained files are saved as:

```text
career_model.pkl
encoders.pkl
```

## 📊 Model Evaluation

The training script calculates:

* Training Accuracy
* Testing Accuracy
* Classification Report

Run `train_model.py` to view the current evaluation results.
